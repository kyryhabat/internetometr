# Internetometr

Простой скрипт на Python для измерения скорости скачивания файлов через HTTP/HTTPS.

## Возможности

- Принимает URL файла через командную строку.
- Выполняет 10 последовательных GET-запросов.
- Измеряет время выполнения каждого запроса.
- Подсчитывает общий объём скачанных данных.
- Вычисляет среднее время запроса.
- Показывает среднюю скорость скачивания в МБ/с.
- Обрабатывает ошибки HTTP и подключения.

## Требования

Python 3.10+

## Установка

Клонировать репозиторий:

```bash
git clone https://github.com/kyryhabat/internetometr.git
cd internetometr
```

Создать виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python speed_test.py 'https://www.python.org/static/img/python-logo.png'
```

Для измерения скорости рекомендуется использовать прямую ссылку на файл размером 10–50 МБ.

## Принцип работы

Скрипт последовательно скачивает файл 10 раз.

Время каждого запроса измеряется с помощью time.perf_counter().

Данные считываются частями с помощью requests.iter_content(),
что позволяет не хранить весь файл в оперативной памяти.

Среднее время = суммарное время / 10.

Средняя скорость = общий объём скачанных данных / суммарное время.

1 МБ = 1024 × 1024 байт.

Задержки между запросами не учитываются при вычислении скорости.

## Ограничения

Результат зависит от выбранного сервера, сетевой задержки
и текущей загрузки соединения.

Некоторые серверы могут ограничивать количество запросов
и возвращать HTTP 429.
